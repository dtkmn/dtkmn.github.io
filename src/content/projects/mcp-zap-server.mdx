## What it is

MCP ZAP Server lets AI agents import API schemas, run OWASP ZAP scanning workflows, and retrieve
structured findings. API-key/JWT authentication, tool scopes, policy, URL validation, quotas, limits,
and audit events govern those workflows; Docker Compose, Helm, and CI security-gate examples support deployment.

[MCP Gateway Core](/projects/mcp-gateway-core/) supplies shared Java contracts for tool identity,
authorization, policy, audit, abuse protection, and adapter behavior. MCP ZAP Server owns the
scanner-specific runtime.

## Get started

As of October 1, 2026, the latest published release is
[v0.13.0](https://github.com/dtkmn/mcp-zap-server/releases/tag/v0.13.0).
Use the [Self-Serve First Run guide](https://danieltse.org/mcp-zap-server/getting-started/self-serve-first-run/)
for the Docker Compose demo scan, and the
[MCP Client Setup guide](https://danieltse.org/mcp-zap-server/getting-started/mcp-client-authentication/)
for authenticated client connections.

This release consumes MCP Gateway Core and its WebFlux adapter at `0.10.0`.
Gateway `0.11.0` is now published separately; its additions are not part of this
ZAP release. See the [Gateway project page](/projects/mcp-gateway-core/)
for the library's integration choices and release details.

## Client Spider and browser authentication

**v0.13.0** adds **Client Spider** for JavaScript-driven applications, with direct and queued crawls,
status and cancellation, and operator-managed browser login profiles. These profiles currently support
Client Spider; form-login profiles remain the path for guided authenticated active scans. Upgrade all
workers sharing a scan queue before submitting Client Spider jobs. The
[Client Spider guide](https://danieltse.org/mcp-zap-server/scanning/client-spider/) covers setup,
authentication, and execution modes.

Juice Shop validation covered anonymous and authenticated crawls in both modes. Crawl completion does
not establish coverage; inspect discovered content and authenticated requests. Findings enter shared
ZAP reports after passive analysis. There is no dedicated Client Spider discovery-list tool or isolated
per-crawl report, and testing did not establish a coverage advantage over other crawlers. In the tested
Juice Shop setup, a documented
[pre-login visit workaround](https://danieltse.org/mcp-zap-server/scanning/client-spider/#browser-storage-alerts-missing-during-login)
recovered browser-storage alerts in fresh sessions; it is not automatic.
