## What it is

This project turns OWASP ZAP into an MCP-accessible security tool so an AI agent can import API
schemas, run scanning workflows, and pull structured findings without falling back to brittle shell
scripts.

## Why it matters

Many MCP demos stop at convenience. This one is stronger because it sits on a real operational
boundary: security automation. The interesting question is not whether an agent can call a tool. It
is whether that tool can be exposed in a way that is safe enough, observable enough, and packaged
well enough to fit into actual engineering workflows.

## What makes it credible

The repository has enough surface area to show that it has moved past novelty:

- a documentation site with security, deployment, observability, and operator runbooks,
- a demo path that shows the workflow end to end,
- release notes and changelog discipline,
- GitHub Actions and GitLab security-gate examples,
- Docker Compose and Helm deployment material,
- API-key/JWT auth, tool scopes, runtime policy bundles, audit events, rate limits, workspace quotas,
  and target URL validation.

The June 10 v0.9.0 release-branch work makes the proof sharper. Policy, audit, and abuse-protection
handling now route through shared gateway-core adapter boundaries instead of living as one-off local
filters. The security-gate examples reject mutable image tags. The docs and validation commands make
the release process inspectable.

The security-alert context is part of the proof, not something to airbrush out. On June 10, GitHub
dependency alerts flagged high-severity Netty issues; the branch moved to Netty `4.2.15.Final` and
the relevant Dependabot alerts were marked fixed the same morning. Snyk still showed high-severity
framework and Micrometer findings that need triage. That is what production-adjacent maintenance
looks like: alerts arrive, fixes land, unresolved work stays visible.

That combination is exactly why this deserves a page here. The repository handles setup and usage.
This page explains why the project matters in the first place.
